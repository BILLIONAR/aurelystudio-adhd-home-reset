# AurelyStudio ADHD Home Reset

A local-first home planner. Enter your name or nickname, add your first task, and plan one small reset. New homes begin without sample tasks or fabricated statistics. Theme Studio, calendar, charts, backup/restore and Print / PDF Center are included. Data is saved in your browser; export backups in Settings. No account or cloud sync.

Open index.html with its assets beside it, or serve this directory over HTTPS. No build step. All assets load from this app directory. Photography credits and font licenses are included.
